# Chapter 2, solution 6

Here are two ways to define the `exec` function:
```
exec1(x, y, op=+) = op(x, y)
exec2(x, y; op=+) = op(x, y)
```
The first of them uses positional arguments, and the second a keyword argument.
Here is a difference in how they would be called:
```
julia> exec1(2, 3, *)
6

julia> exec2(2, 3; op=*)
6
```
